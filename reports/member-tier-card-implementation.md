## 5. Component Architecture

The duplicated four-card rate overview and four-card detailed tier grid were merged into one server-rendered, progressively enhanced component:

- Root: `<section class="member-tier" data-member-tier-tabs>`
- Visual stage: four tier visual cards rendered in source order.
- Selector: four accessible tab buttons in one horizontally scrollable pill row.
- Content: four server-rendered tab panels containing benefits, invoice example, and approved status text.

No separate duplicated desktop/mobile component was added. Without JavaScript, all tier content remains visible in document order. With JavaScript enabled, Bronze is activated by default and inactive cards/panels are hidden.
