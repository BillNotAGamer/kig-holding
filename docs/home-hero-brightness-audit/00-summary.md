# Home Hero Brightness Audit Summary

## Current Issue

The Home hero slider on [`/`] renders darker than intended. The food photography is visible, but the combined image filter and overlay stack makes the dishes feel underexposed, especially on mobile.

## Files Inspected

- `Views/Home/Index.cshtml`
- `wwwroot/js/home-hero-slider.js`
- `wwwroot/css/input.css`
- `wwwroot/css/site.css`
- `tailwind.config.js`
- `wwwroot/images/home/images/banner1.webp`
- `wwwroot/images/home/images/banner2.webp`
- `wwwroot/images/home/images/banner3.webp`

## Current Hero Image Sources

- `/images/home/images/banner1.webp`
- `/images/home/images/banner2.webp`
- `/images/home/images/banner3.webp`

## Main Cause of Darkness

The darkness is not coming from a single source.

It is the combination of:

1. dark source photography with black tabletop/background composition,
2. a CSS image filter on `.champong-hero__media`:
   - `brightness(0.92)`
3. a full-slide `::before` black vertical gradient,
4. a stronger `::after` directional black gradient that changes per slide,
5. a heavier mobile-only overlay override.

The JS does not darken the slide directly. It only swaps active state, opacity, z-index, and reveal timing.

## Recommended Fix Direction

Use a hero-scoped CSS adjustment in `wwwroot/css/input.css`.

Safest direction:

- keep the current images,
- keep the current slider JS,
- keep the current markup/content,
- slightly increase image brightness in `.champong-hero__media`,
- slightly reduce the darkest overlay stops in the hero pseudo-element gradients,
- keep an overlay in place for readability.
