## Tailwind CSS Theme Tokens (`tailwind.config.js`)

### 1. Color Palette
* **Accent Brand Red**: `bg-brand-red` / `text-brand-red` (`#E50914`)
* **Accent Deep**: `bg-brand-redDark` (`#B91C1C`)
* **Base Dark**: `bg-brand-black` (`#0B0B0B`)
* **Base Charcoal**: `bg-brand-charcoal` (`#1F2937`)
* **Base Cream (Highlights)**: `text-brand-cream` / `text-brand-goldSoft` (`#F9FAFB` / `#E7D9BD`)
* **Base Light (Admin Background)**: `bg-brand-light` (`#FAF8F3`)
* **Base Gray**: `text-brand-gray` (`#6B7280`)
* **Base Border**: `border-brand-border` (`#E5E7EB`)

### 2. Typography
* **Font Family**: `Quicksand` sans-serif font family is applied universally via `font-sans`.
* **Font Sizes**:
  * `text-hero`: `4.5rem` (line-height `0.95`, letter-spacing `0`)
  * `text-display`: `3.5rem` (line-height `1`, letter-spacing `0`)
  * `text-section`: `2.5rem` (line-height `1.1`, letter-spacing `0`)
  * `text-kicker`: `0.75rem` (line-height `1`, letter-spacing `0.14em`)

### 3. Animations Keyframes
* `fadeUp`: Translates element up by `16px` while fading in over `640ms`.
* `fadeIn`: Fades element opacity from `0` to `1` over `420ms`.
* `imageZoom`: Slowly scales images by `1.06` over `7s` (used by hero carousel).
* `buttonGlow`: Pulsates box-shadow glows infinitely over `2.4s`.
* `drawerIn`: Slides side menu in from the right over `280ms`.
* `headerDrop`: Slides sticky header down from the top over `260ms`.

## Frontend Cleanup Opportunities

1. **Swiper JS/CSS Dependencies**: Swiper tags are loaded globally in `_Layout.cshtml`. If no other page relies on Swiper, these tags should be removed to reduce page weight.
2. **Missing Placeholders**: Verify that the placeholder images (such as `/images/placeholders/about-hero.webp` and `food-card.webp`) referenced in older views exist on disk, or replace them with verified assets.
3. **Gold Highlight Variables**: Legacy CSS variables (like `--color-brand-gold` and `--color-brand-gold-soft`) are remapped in `input.css` to redirect to red variables. Cleaning up these old references in stylesheets and layouts will improve code consistency.
